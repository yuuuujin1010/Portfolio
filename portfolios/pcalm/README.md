## 구성

딥글로우 → 클라우드 76인 협업 → APR 시딩 → 포토그레이 릴스 → GS넷비전 채널 운영 → 트렌드 리포트 → 녹색지대 축제.

인플루언서·콘텐츠 마케팅 직접 경험을 먼저 배치하고, 축제는 파트너 조율을 보여주는 보조 사례로 정리했습니다. 공공사업 운영, 가맹 정산, 관련성이 낮은 활동은 본문에서 제외했습니다.

## 검토 상태

2026년 10월 최신 이력서와 이전 포트폴리오를 근거로 작성했습니다. 요청한 64MB 원본 PDF와 합격자 참고 노션은 내용 대조를 완료하지 못했습니다. 원본 자료와 비교한 최종 확정본은 아닙니다.

매출·랭킹·채널 성장 등 캠페인 전체 지표와 본인 수행 업무를 구분했습니다. 포토그레이 릴스 조회수 집계일, 캠페인 수치 산출 범위는 제출 전 확인이 필요합니다. 원본 업무자료를 확인하지 못한 도식은 실제 업무의 구조를 재구성한 것입니다.

게시된 릴스 링크는 이전 포트폴리오에서 확인한 링크이며, 현재 재생 가능 여부는 확인하지 못했습니다.
