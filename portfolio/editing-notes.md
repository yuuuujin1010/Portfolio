# 편집 메모 — 제출용 본문과 분리

- 메인: 어퓨, 올더뮤. 뷰티·웰니스 제품의 인플루언서 선정, 가이드, 운영을 제일 앞에 배치.
- 확장: 포토그레이는 콘텐츠 포맷 기획, 클라우드는 76인 협업 운영을 증명.
- 보강: GS 콘텐츠와 MCN 분석. 축제는 보조 프로젝트로 배치.
- 제외: 정산·미수금, 공공사업 운영, 일반 학생회 SNS 운영, LSM, 키즈풀 행사. 이번 포트폴리오의 인플루언서 직무 메시지를 우선함.
- MCN의 5.5M→17.1M은 약 210.9% 증가로 원본 208%와 불일치. 집계 기준 확인 전 대표 KPI 제외.
- 축제 방문객 수는 자료별 1.4만/3.1만/3.2만 차이가 있어 제외.
- 어퓨 원본 28만+와 이전 정밀 수치 27.4만+ 차이가 있어 원본 표기 사용 및 집계 기준 주석.
- 포토그레이는 원본의 2주 집계 사용. 기존 7일 집계와 혼합하지 않음.
- 기여도는 자기평가. 단독 리딩으로 확장하지 않음. 캠페인 매출은 개인 콘텐츠의 인과적 성과로 쓰지 않음.
- 추가하면 좋은 증빙: 개인정보를 가린 후보 선정표, 콘텐츠 가이드 1장, 검수 수정 전후, 일정표, KPI 집계 기간. 실제 증빙 없이 새로 제작한 운영 자료를 당시 사용 자료처럼 넣지 않음.
- 참고 노션은 인플루언서 마케팅 팀장 경력 포트폴리오. 프로젝트 중심 구조를 참고했고 조직 구축·팀 리딩·ROAS 실적은 가져오지 않음.
- 피캄의 실제 지원 공고/JD는 제공되지 않았으므로 공고 맞춤 최종본이 아닌 인플루언서·콘텐츠 마케팅 중심 공통본.
