# 안유진 | 콘텐츠 · 인플루언서 마케팅

[PDF 포트폴리오](portfolio.pdf) · [텍스트 본문](portfolio.md) · [HTML 파일](portfolio.html)

뷰티 인플루언서 협업, 숏폼 기획, GS넷비전 크리에이터 분석, 대규모 시딩 운영 사례를 담았습니다. GS25와 총학생회 녹색지대는 보조 경험으로 정리했습니다.

각 영상 캡처는 해당 원본 콘텐츠로 연결됩니다. 크리에이터 A·B는 화면 내 순서를 구분하는 표기이며 프로젝트 간 같은 인물을 뜻하지 않습니다. GS넷비전 카드에서는 분석 참여 채널로 이동합니다.

HTML 파일은 assets 폴더와 함께 내려받아 열면 됩니다. media-*.html은 노션에서 사용하는 클릭 가능한 미디어 카드의 원본입니다.
